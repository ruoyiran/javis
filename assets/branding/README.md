# Javis branding

The adopted “协作之手” mark is a plum J cradling a coral desktop window. The SVG is the canonical artwork; PNG, ICNS and ICO are exports of the selected vector refinement.

`javis.svg` supplies the application icon and embedded web-page logo/favicon. `javis-mark.svg` is the mark without its tile. `Javis.icns` is bundled in the signed macOS app; the complete directory is copied into `dist/branding` for standalone desktop distributions.

The colors are plum `#6C326A`, coral `#FB5E75`, and blush `#FDECE4`. Icons have transparent outer corners and are available at 1024 pixels in `javis.png`.
