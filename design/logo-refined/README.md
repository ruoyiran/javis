# Javis「协作之手」精修稿

基于用户选中的第 10 版。紫色 J 托举珊瑚色窗口，表达可靠、可控的桌面助手。

本方案已采用为 Javis 的正式图标。生产资源位于 [`assets/branding`](../../assets/branding)，随构建用于 macOS 应用、跨平台分发、设置页和手机页面。本目录保留设计稿及预览。

| 文件 | 用途 |
| --- | --- |
| `mark.svg` | 无底板、透明背景的矢量标志 |
| `app-icon.svg` | 带浅杏色底板的矢量应用图标 |
| `logo-1024.png` | 1024×1024 透明圆角应用图标 |
| `mark-1024.png` | 1024×1024 透明背景标志 |
| `review.png` | 原方案与精修稿、明暗背景及小尺寸预览 |
| `Javis.icns` | macOS 图标资源 |
| `Javis.ico` | Windows 图标资源 |
| `sizes/` | 16、32、64、128、256、512、1024 像素 PNG |
| `brand.json` | 色值与精修说明 |

配色：紫色 `#6C326A`、珊瑚色 `#FB5E75`、浅杏色 `#FDECE4`。

精修保留 J 的托举形象和窗口的 16 度倾角，整理曲线、统一色块，并扩大窗口与内侧弧线之间的留白。
