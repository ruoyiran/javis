# Javis Logo 概念方案

这组候选基于 Javis 的实际定位：独立的桌面 CUA，观察应用窗口、操作控件、验证结果，并尽量保持用户的工作焦点。十个方向刻意使用不同轮廓和配色，供选择后继续精修。

所有候选为 1024×1024 PNG 概念图，尚未接入应用打包。编号对照图为 `overview.png`，小尺寸检查为 `small-sizes.png`。

第 10 版已选中并精修，正式采用的生产资源位于 [`assets/branding`](../../assets/branding)。其余图片保留为概念记录。

| 编号 | 方向 | 设计含义 | 独立图片 |
| --- | --- | --- | --- |
| 01 | J 光标 | 把 J 和光标融合，直接表达桌面操作。 | [01-j-pointer.png](01-j-pointer.png) |
| 02 | 窗口之眼 | 窗口与观察镜头融合，强调先看清再操作。 | [02-window-lens.png](02-window-lens.png) |
| 03 | 观察闭环 | 两段环形轨迹表现观察、执行、再验证。 | [03-observe-act.png](03-observe-act.png) |
| 04 | 安静助手 | 友好的双眼形象，体现不打扰用户的后台助手。 | [04-quiet-assistant.png](04-quiet-assistant.png) |
| 05 | 窗口 J | 窗口里的 J，用负形表达应用窗口和操作入口。 | [05-window-j.png](05-window-j.png) |
| 06 | 迅捷 J | 一笔形成 J 与箭头，突出执行效率。 | [06-swift-j.png](06-swift-j.png) |
| 07 | 精准焦点 | 四角框和光标表达定位窗口、精准行动。 | [07-focus-cursor.png](07-focus-cursor.png) |
| 08 | 桌面桥梁 | 两个窗口由一条路径连接，体现本地和远程协作。 | [08-desktop-bridge.png](08-desktop-bridge.png) |
| 09 | 像素 J | 少量大像素组成 J，呼应 CLI 与开发者工具。 | [09-pixel-j.png](09-pixel-j.png) |
| 10 | 协作之手 | 抽象指尖与托举形状，体现可控、可靠的助手。 | [10-trusted-hand.png](10-trusted-hand.png) |

选择建议：01/05 以 J 为品牌识别，02/03/07 强调观察与准确执行，04 适合更亲和的助手形象，06/09 更突出个性，08/10 强调连接和协作。

选中一个编号后，可继续调整轮廓、配色和负形空间，再制作透明背景母版、macOS `.icns`、Windows `.ico` 和网页图标。
